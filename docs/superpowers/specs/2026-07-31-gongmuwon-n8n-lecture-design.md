# 공무원 대상 n8n 입문 강의자료 — 설계 문서

작성일: 2026-07-31

## 1. 목적과 대상

n8n을 한 번도 써본 적 없는 공무원을 대상으로, 이틀짜리 실습형 강의자료를 만든다. 자료는 정적 HTML 사이트로 제작해 Vercel에 배포하고, 각 단계의 완성 워크플로우를 JSON으로 내려받을 수 있게 한다.

수강생은 코딩 경험이 없다고 가정한다. 따라서 모든 설정은 클릭 순서 단위로 쪼개어 쓰고, 화면 이미지를 최대한 많이 넣는다.

성공 기준: 강사 도움 없이 자료만 보고 따라 해도 1일차 8단계를 완주할 수 있어야 한다.

## 2. 원본 자산

강사 본인 n8n 인스턴스의 지정 프로젝트·폴더에 이미 만들어진 워크플로우를 재료로 쓴다.
(인스턴스 주소와 프로젝트·폴더 id는 이 저장소에 적지 않는다. 공개 저장소로 나갈 수 있는
파일이므로, 접속 정보는 작업 세션에서만 다룬다.)

`[1일차] 01`~`08` 8개는 모두 **동일한 민원 접수 시나리오**를 공유한다. 03~07번이 같은 `샘플 민원` 데이터(이름·연락처·이메일·종류·상세설명)를 사용하므로, 별개 예제 8개가 아니라 하나의 워크플로우를 8단계로 쪼갠 것으로 재구성할 수 있다. 이것이 이 강의자료의 핵심 구조다.

`[2일차] 프로젝트1`은 1일차 누적 결과물과 거의 동일하므로 제외한다.

## 3. 커리큘럼

### 1일차 — 누적 빌드

하나의 워크플로우에 매 강의마다 노드를 하나씩 얹는다. 수강생은 8번 새로 만드는 것이 아니라 하나를 계속 키운다.

| 강 | 제목 | 추가되는 것 | 새 개념 |
|---|---|---|---|
| 00 | 왜 자동화인가 + 준비물 | — | n8n이 무엇인가 |
| 01 | 첫 워크플로우 | 수동실행 → Set | 노드, 연결, 실행 |
| 02 | 데이터 흐름과 표현식 | + Set | `{{ $json.필드 }}` |
| 03 | 구글 시트 자동 기록 | + Google Sheets | 외부 서비스 연결, 자격증명 |
| 04 | 이메일 자동 발송 | + Gmail | 여러 필드를 문장에 끼워넣기 |
| 05 | 캘린더 일정 자동 생성 | + Google Calendar | 날짜 계산 `$now.plus()` |
| 06 | AI 안내문 자동 생성 | + Gemini | LLM 노드, 프롬프트 |
| 07 | 조건 분기 | + IF | 참/거짓 두 갈래 |
| 08 | 입력 폼으로 실제 접수 | 트리거 교체 | Form Trigger |

08강에서 수동 실행 트리거를 Form Trigger로 교체하면서 "이제 진짜 민원을 받아봅시다"로 1일차를 끝맺는다.

1일차는 구글 계정과 Gemini API 키만 있으면 완주된다. 텔레그램은 필요하지 않다.

### 2일차 — 독립 프로젝트 4개

| # | 제목 | 구성 | 새 개념 |
|---|---|---|---|
| 00 | 2일차 준비 | — | 텔레그램 봇 만들기 |
| P1 | 공문서 요약 서비스 | Form(PDF) → 추출 → Gemini → 텔레그램 | 파일 업로드, PDF 텍스트 추출 |
| P2 | 매일 아침 민원 브리핑 봇 | Schedule → Sheets → Gemini → 메일+텔레그램 | 정해진 시각 자동 실행, 여러 건 요약 |
| P3 | AI 민원 자동 분류·답변 초안 | Form → Gemini → Sheets | AI 분류 결과를 구조화해 저장 |
| P4 | 날씨 알리미 | Schedule → 기상청 API → 가공 → 텔레그램 | 공공데이터포털 API 연동 |

프로젝트마다 새 개념을 정확히 하나씩만 도입한다. 나머지는 1일차에서 배운 노드의 재조합이다.

원본 워크플로우의 알림 채널(Gmail / 텔레그램)을 그대로 유지한다.

## 4. Gemini 모델

**`models/gemini-2.5-flash`** 로 고정한다.

- 공식 가격 페이지에서 Free Tier "Free of charge"(입력·출력 모두) 확인됨
- 정식 출시 모델 (preview 아님)
- n8n Gemini 노드 v1의 기본값

**함정**: n8n Gemini 노드가 버전 1.1 이상이면 기본값이 `models/gemini-3-flash-preview`가 된다. preview 모델은 예고 없이 변경·제거될 수 있어 강의에 부적합하다. AI가 등장하는 모든 강의(1일차 06강, P1~P3)에서 **기본값을 그대로 두지 말고 직접 `gemini-2.5-flash`를 선택하라**고 명시한다.

**대체 모델**: 할당량 초과 시 `models/gemini-2.5-flash-lite` (역시 무료, 처리량 더 넉넉).

구글이 2025년 12월부터 무료 한도를 공개 표로 게시하지 않고 계정별 대시보드로 옮겼으므로, 정확한 한도는 AI Studio 화면에서 확인하도록 안내한다.

## 5. 사이트 구조

```
public/
  index.html                커리큘럼 개요 + 전체 목차
  prep/day1.html            준비물 ①: 구글 계정, Gemini API 키
  prep/day2.html            준비물 ②: 텔레그램 봇, 공공데이터포털
  day1/01.html ~ 08.html    1일차 8강
  day2/p1.html ~ p4.html    2일차 4프로젝트
  assets/style.css          공통 디자인
  assets/flow.css           SVG 플로우 다이어그램 스타일
  assets/img/               캡처 이미지
  downloads/
    day1-01.json ~ 08.json  단계별 스냅샷 8개
    day2-p1.json ~ p4.json  프로젝트 4개
vercel.json
```

빌드 도구를 쓰지 않는다. Vercel에 그대로 올라간다.

### 페이지 내부 구조

모든 강의 페이지가 같은 틀을 따른다.

1. **이번 시간에 만들 것** — 완성 화면 미리보기, 한 줄 요약
2. **지난 시간까지의 흐름** — SVG 플로우. 기존 노드는 회색, 새로 붙이는 노드는 강조색
3. **왜 이게 필요한가** — 공무원 업무 맥락 2~3문장
4. **따라하기** — 번호 매긴 단계, 각 단계에 `[그림 N-N]` 자리
5. **실행하고 확인하기** — 성공 시 보이는 화면
6. **안 될 때** — 흔한 실수 3가지와 해결법
7. **이번 단계 워크플로우 받기** — JSON 다운로드 버튼

2번의 SVG 플로우가 누적 학습의 핵심 장치다. 새 노드만 색이 다르므로 지금 무엇을 붙이는 중인지 한눈에 보인다.

## 6. 이미지 처리

하이브리드 방식을 쓴다.

- **플로우 구조도**: SVG로 직접 작성해 넣는다. n8n 버전이 바뀌어도 깨지지 않는다.
- **n8n 실제 화면**: 번호 매긴 자리표시자를 두고, 어디를 캡처해야 하는지 안내문을 넣는다.

자리표시자 형식:

```html
<figure class="capture-todo" id="fig-3-2">
  <figcaption>[그림 3-2] Google Sheets 노드 설정 화면</figcaption>
  <div class="capture-guide">
    캡처 위치: n8n → 노드 더블클릭 → 좌측 파라미터 패널 전체
  </div>
</figure>
```

나중에 원하면 일부를 브라우저 자동 캡처로 교체할 수 있다.

## 7. 배포 정책

승인 전에는 외부로 아무것도 내보내지 않는다.

| 대상 | 승인 전 | 승인 후 |
|---|---|---|
| Vercel 웹 배포 | 하지 않음. 로컬 파일로만 확인 | 배포 |
| n8n 워크플로우 생성 | 하지 않음. 로컬 JSON으로만 작성 | n8n에 생성 |

워크플로우 품질은 `validate_workflow`(로컬 JSON 검증, n8n에 생성하지 않음)로 확보한다. 실제 실행 테스트는 n8n에 올려야만 가능하므로, 개발 중 필요해지면 그때 따로 승인을 받는다.

### 폴더 제약

n8n 공개 API는 폴더를 지원하지 않는다. `n8n_create_workflow`에 폴더/프로젝트 파라미터가 없고, `GET /workflows`도 폴더 정보를 반환하지 않으며 `folderId` 쿼리 파라미터를 무시한다.

따라서 생성된 워크플로우는 프로젝트 최상단에 만들어진다. 대응:

- 이름을 `[공무원] 1일차 완성 - 민원 접수 자동화`, `[공무원] P1 공문서 요약` 형식으로 통일한다
- 생성 후 n8n UI에서 "공무원" 폴더로 드래그해 옮기는 절차를 안내한다

한 번에 전부 만들지 않는다. 단계마다 확인을 받고 진행한다.

| 단계 | 산출물 | 확인 시점 |
|---|---|---|
| 1 | 뼈대 — index, 준비물 2p, 14개 페이지 골격, 공통 CSS, SVG 플로우 컴포넌트, 다운로드 버튼 | 톤·디자인 확인 |

## 9. 열린 항목

- **00강 자동화 전/후 비교 수치**: 예시 수치(수기 8분 vs 자동 20초)를 쓸지, 실제 경험 수치를 받을지 미정. 1단계 뼈대 작성 시점에는 예시로 채우고 나중에 교체 가능하게 둔다.
- **기상청 API 키 신청 리드타임**: 공공데이터포털 승인에 시간이 걸릴 수 있다. 실제 사용은 2일차 P4지만, 1일차 준비물 페이지 맨 아래에 "2일차에 쓸 것 — 지금 미리 신청해두세요" 항목으로 분리해 넣는다. 1일차 실습 자체에는 필요하지 않다는 점을 명시해, 없어도 1일차를 완주할 수 있음을 분명히 한다.
- **git 저장소**: 현재 프로젝트 폴더는 git 저장소가 아니다. Vercel 배포를 git 연동으로 할지, CLI 직접 업로드로 할지에 따라 `git init` 필요 여부가 갈린다. 5단계 진입 전에 결정한다.
