07 조건에 따라 나누기

민원 종류로 담당자를 가릅니다

왜 이게 필요한가

  • 쓰레기 무단투기는 환경 담당, 도로 파임은 도로 담당처럼 민원 종류마다 담당이 다르지만, 지금까지 만든 워크플로우는 모든 민원을 똑같이 처리한다
  • 실제 업무에서 담당을 가르는 판단은 의외로 단순함 — 종류 칸 하나만 보면 됨
  • 해결: IF 노드로 조건이 맞으면 이쪽 길, 아니면 저쪽 길로 자동 분기
여기서부터 워크플로우가 "판단"을 합니다 지금까지 만든 노드들은 시키는 일을 순서대로 했을 뿐이지만, IF 노드는 처음으로 들어온 값을 보고 갈 길을 스스로 고릅니다.

이번 시간에 만들 것

민원이 '생활' 관련인지 아닌지를 조건으로 나누어, 담당자에게 서로 다른 경로로 전달되게 만듭니다.

따라하기

  1. If 노드 추가하기 샘플 민원 오른쪽 + → If
  2. 조건 입력하기 왼쪽 값 표현식 전환 → {{ $json.종류 }}, 연산자 String → is equal to, 오른쪽 값은 글자 그대로 생활
  3. 노드 이름 바꾸기 생활인가?로 변경
  4. 두 개의 출력 확인하기 위쪽 = true(참), 아래쪽 = false(거짓)
  5. 참 출력에 담당자 메일 연결하기 위쪽 + → Gmail(04강 자격증명 재사용)

    To = 본인 이메일(글자 그대로)
    Subject = [생활 관련] 민원
    Message = 표현식, 생활 관련 민원: {{ $json.이름 }}

    노드 이름 → 생활 담당자
  6. 거짓 출력에 담당자 메일 연결하기 아래쪽 + → Gmail

    To = 본인 이메일
    Subject = [일반] 민원
    Message = 표현식, 일반 민원: {{ $json.이름 }}

    노드 이름 → 일반 담당자
두 담당자 주소가 같아도 괜찮은 이유 실습에서는 두 노드 모두 본인 주소로 두는 편이 낫습니다. 제목만 보고 어느 갈래를 탔는지 바로 비교할 수 있습니다.

실행하고 확인하기

  • 종류가 지금 생활 → Execute workflow → [생활 관련] 민원만 도착
  • 종류를 음식물로 바꿔 재실행 → [일반] 민원 도착 = 성공, 확인 후 다시 생활로 되돌림

안 될 때

  • 항상 [일반] 민원만 도착 — 왼쪽 값 Expression 모드 확인
  • 메일이 두 통 다 옴 — 각 출력에 다른 노드가 연결됐는지 확인
  • 값 비교 안 됨 — 오른쪽 값에 따옴표 없이 생활만 입력했는지 확인

확인 문제

객관식Q1. If 노드에서 출력 연결점 중 조건이 참(true)일 때 나가는 자리는 어느 쪽인가요?

  1. 위쪽
  2. 아래쪽
  3. 왼쪽
  4. 둘 다 동시에
정답 확인

정답: ① 위쪽이 참(true), 아래쪽이 거짓(false)일 때 나가는 자리입니다.

객관식Q2. 조건 왼쪽 값을 표현식(Expression) 모드로 바꾸지 않으면 어떤 문제가 생기나요?

  1. 워크플로우가 실행되지 않는다
  2. {{ $json.종류 }}라는 글자 자체와 비교하게 되어 항상 다르다고 판단한다
  3. 노드가 자동으로 삭제된다
  4. 메일이 두 통 발송된다
정답 확인

정답: ② 표현식 모드가 아니면 실제 값이 아니라 글자 그대로를 비교하므로 조건이 항상 거짓으로 판단됩니다.

단답형Q3. 이번 시간에 만든 If 노드의 이름은 무엇이며, 무엇과 무엇을 비교하나요?

정답 확인

정답: 생활인가? — {{ $json.종류 }}와 글자 생활이 같은지 비교합니다.

이번 단계 워크플로우 받기

따라오다 막혔다면 이 파일을 받아 n8n에서 불러오면 이어서 진행할 수 있습니다.

불러온 뒤 반드시 확인하세요 이 파일에는 자격증명이 들어 있지 않습니다. 불러온 뒤 시트에 기록· 접수 메일 보내기·처리 마감 일정· Google Gemini Chat Model·생활 담당자· 일반 담당자 여섯 노드를 각각 열어 자격증명을 다시 골라야 합니다(Gemini는 구글 로그인 화면이 아니라 API 키를 새로 입력하는 화면입니다). 시트에 기록의 Document 칸에는 여기에_본인_시트_ID 자리표시자가 들어 있습니다. 본인이메일@example.com 자리표시자는 네 군데에 들어 있습니다 — 샘플 민원의 이메일 값, 처리 마감 일정의 Calendar 칸, 그리고 생활 담당자·일반 담당자 두 노드의 To 칸입니다. 네 곳 모두 본인 주소로 바꿔야 이번 강의의 갈래 확인이 됩니다. 시트 탭 이름은 시트1로 들어 있으니 본인 시트의 탭 이름이 다르면 목록에서 다시 골라야 합니다.
