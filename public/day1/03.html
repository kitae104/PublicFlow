03 구글 시트에 자동 기록

만든 데이터를 시트에 쌓습니다

왜 이게 필요한가

  • 전화 받으면 메모지에 적고 → 접수 대장에 손으로 옮김 → 오타·누락 발생
  • 대장은 내 컴퓨터 안에만 있어 현황 공유 어려움
  • 해결: 접수와 동시에 구글 시트에 저절로 한 줄 쌓임 → 오타·누락 없음, 링크만으로 현황 공유
이번 시간부터 밖깥 서비스와 연결

구글 시트에 쓰려면 자격증명(n8n이 내 구글 계정을 써도 된다는 허락)이 필요합니다. 한 번 만들면 4·5강에서는 다시 만들 필요 없습니다.

n8n을 클라우드로 쓰면 구글 로그인 버튼만, 설치형은 Client ID·Client Secret을 먼저 넣어야 합니다. n8n을 쓰는 두 가지 방법 — 구글 연결 항목을 미리 확인하세요.

이번 시간에 만들 것

샘플 민원 데이터 → 구글 시트에 한 줄씩 자동 적재

구글 계정과 시트 필요 준비물 ① 구글 계정, 시트 준비를 먼저 확인하세요(준비물).

샘플 민원은 07강까지 재사용 — 필드 이름 기억해두기

따라하기

  1. 기존 노드 두 개 지우기 값 만들기·값 가져오기 선택 후 Delete
  2. 샘플 민원 노드 추가하기 수동 실행 오른쪽 + → Edit Fields (Set) → 이름을 샘플 민원으로
  3. 필드 5개 채우기

    이름 = 김기태
    연락처 = 010-1111-2222
    이메일 = 본인 Gmail 주소
    종류 = 생활
    상세설명 = 집 앞에 쓰레기가 무단 투기되어 있습니다.

    이메일은 본인 실제 Gmail 주소 — 04강부터 발송됨
  4. Google Sheets 노드 추가하기 샘플 민원 오른쪽 + → Google Sheets
  5. 자격증명 연결하기 Credential → Sign in with Google → 개인 계정 선택 → 허용 설치형은 or setup manually → Client ID·Secret 입력
    기관 계정(@korea.kr 등)은 막혀 있을 수 있음 — 오류 나면 개인 Gmail로 재시도
  6. Resource·Operation 설정하기 Resource = Sheet Within Document(기본값), Operation = Append Row로 변경
  7. 시트 고르기 Document → Choose… → 준비물 시트 선택
  8. 탭 고르기 Sheet → 탭 선택(시트1 등)
  9. 칸 매핑하기 여섯 칸 각각 표현식 전환 후 입력:

    이름 = {{ $json.이름 }}
    연락처 = {{ $json.연락처 }}
    이메일 = {{ $json.이메일 }}
    종류 = {{ $json.종류 }}
    상세설명 = {{ $json.상세설명 }}
    등록일 = {{ $now.toFormat('yyyy-MM-dd') }}

    여섯 칸 모두 왼쪽에 fx 표시 확인
  10. 노드 이름 바꾸기 시트에 기록으로 변경

실행하고 확인하기

  • Execute workflow → 구글 시트 새로고침
  • 2행에 입력값 확인, 등록일에 오늘 날짜 = 성공

안 될 때

  • Document 목록이 비어 있음 — 자격증명 연결 재확인
  • 값이 엉뚱한 칸에 들어감 — 시트 머리글 철자(이름·연락처·이메일·종류·상세설명·등록일) 확인
  • 일부 칸에 {{ $json.이름 }} 그대로 들어감 — 그 칸의 표현식 전환 스위치 확인
  • 권한 오류 — 기관 계정 대신 개인 구글 계정으로 재연결

확인 문제

객관식Q1. 구글 시트 노드의 Operation을 무엇으로 바꿔야 한 줄을 추가할 수 있나요?

  1. Get Row(s)
  2. Append Row
  3. Delete Row
  4. Update Row
정답 확인

정답: ② Append Row가 시트 맨 아래에 새 줄을 덧붙이는 동작입니다.

객관식Q2. 칸 매핑 시 {{ $now.toFormat('yyyy-MM-dd') }}를 입력하기 전에 반드시 해야 하는 것은?

  1. 구글 계정 재로그인
  2. 해당 칸을 표현식(Expression) 모드로 전환
  3. 시트 탭 새로 만들기
  4. 워크플로우 이름 변경
정답 확인

정답: ② 표현식 전환 스위치를 누르지 않으면 입력한 글자가 계산식이 아니라 그대로 시트에 들어갑니다.

단답형Q3. 이번 강의에서 새로 만든 로그인 단계(자격증명)의 이름은 무엇이며, 이것이 하는 역할은 무엇인가요?

정답 확인

정답: 자격증명 — n8n이 내 구글 계정(구글 시트 등)을 대신 사용해도 된다는 허락을 저장해둔 것입니다.

불러온 뒤 반드시 확인하세요 이 파일에는 자격증명이 들어 있지 않습니다. 불러온 뒤 시트에 기록 노드를 열어 자격증명을 다시 골라야 합니다. Document 칸에는 여기에_본인_시트_ID라는 자리표시자가, 샘플 민원 노드의 이메일 값에는 본인이메일@example.com이라는 자리표시자가 들어 있으므로 각각 본인 시트·본인 주소로 바꿔야 합니다. 시트 탭 이름은 시트1로 들어 있으니, 본인 시트의 탭 이름이 다르면 Sheet 목록에서 다시 골라야 합니다.
