06 AI 안내문 자동 생성

Gemini가 안내문 초안을 씁니다

왜 이게 필요한가

  • 민원 안내문은 대부분 비슷한 말이지만 매번 빈 화면에서 새로 쓰다 보니, 지난번 것을 복사해 오면 앞 민원 내용이 한 줄 남아 그대로 나가는 사고가 난다
  • 글쓰기에서 가장 오래 걸리는 건 다듬는 단계가 아니라 첫 문장을 시작하는 단계다
  • 해결: AI가 민원 내용을 받아 안내문 초안을 작성 → 담당자는 백지가 아니라 이미 채워진 글을 읽고 고치기만
AI 초안은 결재가 아님 AI는 사실이 아닌 내용도 그럴듯하게 쓸 수 있습니다. 법령 조항·처리 기한·담당 부서와 같은 핵심 정보는 반드시 사람이 확인 후 발송해야 합니다. 이 강좌에서도 자동 발송은 하지 않고 화면 확인까지만 만듭니다.

이번 시간에 만들 것

접수된 민원 내용을 바탕으로 Gemini가 담당자용 안내문 초안을 자동으로 작성하는 단계를 추가합니다.

Gemini API 키 필요 준비물 ① Gemini API 키 발급을 먼저 확인하세요.

두 노드는 나란히 이어지지 않습니다 — 모델 노드는 아래에 점선으로 매달립니다.

따라하기

이번에는 노드가 두 개 붙습니다 지금까지는 새 노드 하나만 추가했지만, AI를 쓰려면 "무엇을 시킬지"를 맡는 Basic LLM Chain 노드와 "어떤 AI 모델을 쓸지"를 맡는 Google Gemini Chat Model 노드가 짝을 이뤄야 합니다. 아래 순서대로 하나씩 붙입니다.
  1. Basic LLM Chain 노드 추가하기 샘플 민원 오른쪽 + → Basic LLM Chain
  2. 모델 연결하기 노드 아래쪽 Model 자리 클릭 → 검색 → Google Gemini Chat Model
    비슷한 이름 주의 — Google Gemini Tool 등은 다른 노드. 반드시 Google Gemini Chat Model
  3. Gemini 자격증명 연결하기 Credential → My own credential → Create new credential → API Key에 발급받은 키 붙여넣기 → Save Host·Allowed HTTP Request Domains는 그대로 둠 저장 시 Connection tested successfully 확인
  4. 모델 직접 고르기 Model 드롭다운 → models/gemini-2.5-flash 직접 선택
    자동 채워진 값 그대로 두면 안 됨 — preview 모델은 예고 없이 사라질 수 있음. 반드시 models/gemini-2.5-flash 직접 선택
  5. 프롬프트 작성하기 Source for Prompt (User Message) → Define below, 아래 내용 붙여넣기

    당신은 친절한 시청 민원 담당 공무원입니다.
    아래 민원 접수 내용을 바탕으로, 민원인에게 보낼 정중한 '접수 확인 안내문'을 작성해 주세요.

    [작성 규칙]
    - 존댓말을 사용하고, 4~6문장으로 작성합니다.
    - 민원이 정상적으로 접수되었음을 안내합니다.
    - 처리에는 다소 시간이 걸릴 수 있음을 부드럽게 안내합니다.
    - 마지막은 '감사합니다.'로 끝맺습니다.

    [민원 접수 내용]
    - 접수자명: {{ $json.이름 }}
    - 민원 종류: {{ $json.종류 }}
    - 상세 설명: {{ $json.상세설명 }}

  6. 노드 이름 바꾸기 AI 안내문 작성으로 변경

실행하고 확인하기

  • Execute workflow → AI 안내문 작성 출력 확인
  • text에 4~6문장 안내문 생성 = 성공(매번 문장 조금씩 달라짐)
  • 이 안내문은 자동 전송되지 않음 — 확인 용도

안 될 때

  • API 키 오류 — 키 재확인, 앞뒤 공백 확인
  • 할당량 초과 — models/gemini-2.5-flash-lite로 변경
  • 결과가 영어 — 프롬프트 Define below 및 내용 확인
  • 모델 목록에 안 보임 — 자격증명 연결 재확인

확인 문제

객관식Q1. AI에게 시킬 일을 정의하는 노드와 어떤 AI 모델을 쓸지 정의하는 노드를 각각 무엇이라 하나요?

  1. Basic LLM Chain / Google Gemini Chat Model
  2. Google Sheets / Gmail
  3. If / Aggregate
  4. Schedule Trigger / Code
정답 확인

정답: ① Basic LLM Chain이 프롬프트를 맡고, Google Gemini Chat Model이 아래에 매달려 실제 AI 모델을 담당합니다.

객관식Q2. 모델 이름에 preview가 들어간 것을 그대로 두면 안 되는 이유는?

  1. 속도가 느려서
  2. 구글이 예고 없이 이름을 바꾸거나 없앨 수 있어서
  3. 한글을 지원하지 않아서
  4. 비용이 더 비싸서
정답 확인

정답: ② preview 모델은 실습 도중 갑자기 오류가 날 위험이 있어 models/gemini-2.5-flash를 직접 골라야 합니다.

이번 단계 워크플로우 받기

불러온 뒤 반드시 확인하세요 이 파일에는 자격증명이 들어 있지 않습니다. 불러온 뒤 시트에 기록· 접수 메일 보내기·처리 마감 일정· Google Gemini Chat Model 네 노드를 각각 열어 자격증명을 다시 골라야 합니다(Gemini는 구글 로그인 화면이 아니라 API 키를 새로 입력하는 화면입니다). 시트에 기록의 Document 칸, 처리 마감 일정의 Calendar 칸, 샘플 민원 노드의 이메일 값에는 각각 여기에_본인_시트_ID·본인이메일@example.com 자리표시자가 들어 있으므로 본인 값으로 바꿔야 합니다. 시트 탭 이름은 시트1로 들어 있으니 본인 시트의 탭 이름이 다르면 목록에서 다시 골라야 합니다.
