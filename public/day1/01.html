01 첫 워크플로우

n8n에서 무언가를 만들고 실행해봅니다

이번 시간에 만들 것

실행 버튼을 누르면 인사말이라는 값이 만들어지는, 가장 단순한 워크플로우를 만듭니다.

지금까지의 흐름

수동 실행트리거
▶
값 만들기Set

이번 시간에 새로 만드는 노드

왜 이게 필요한가

모든 자동화는 "언제 시작할지"와 "무엇을 할지" 두 가지로 이뤄집니다. n8n에서는 앞의 것을 트리거, 뒤의 것을 노드라고 부릅니다. 지금은 가장 단순한 형태 — 내가 버튼을 누르면(트리거) 값을 하나 만든다(노드) — 를 만들어 이 구조에 익숙해집니다.

따라하기

  1. 새 워크플로우 만들기 n8n 화면 오른쪽 위 Create Workflow 버튼을 누릅니다.
  2. 트리거 추가하기 캔버스 가운데 Add first step…을 누르고 Trigger manually를 고릅니다. 직접 실행 버튼을 눌러 시작하는 트리거입니다.
  3. Set 노드 붙이기 방금 만든 노드 오른쪽 +를 누르고 Edit Fields (Set)를 고릅니다.
  4. 값 채우기 이름에 인사말, 값에 안녕하세요, 홍길동님을 넣습니다.
  5. 이름 바꾸기 노드 이름을 값 만들기로 바꿉니다. 노드가 많아지면 이름이 곧 설명서가 됩니다.

실행하고 확인하기

아래쪽 Execute workflow를 누릅니다. 노드마다 초록 체크가 뜨고, 값 만들기를 누르면 오른쪽에 인사말: 안녕하세요, 홍길동님이 보이면 성공입니다.

안 될 때

실행 버튼이 안 보입니다 — 트리거 노드가 없으면 실행할 수 없습니다. 2단계를 다시 확인하세요.

두 노드가 선으로 이어지지 않았습니다 — 노드 오른쪽 동그라미를 끌어다 다음 노드 왼쪽에 놓으면 연결됩니다.

값이 비어 보입니다 — 이름 칸과 값 칸을 바꿔 넣지 않았는지 확인하세요.

이번 단계 워크플로우 받기

따라오다 막혔다면 이 파일을 받아 n8n에서 불러오면 이어서 진행할 수 있습니다.
