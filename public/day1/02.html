02 데이터 흐름과 표현식

앞 노드의 값을 가져다 씁니다

왜 이게 필요한가

같은 서식의 안내 메일을 여러 사람에게 보내본 적이 있을 겁니다. 본문은 똑같고 이름과 연락처만 바뀌는 그런 메일 말입니다. 하나를 써놓고 복사해서 이름만 고쳐가며 보내다 보면, 김철수 님께 갈 메일에 박영희라는 이름이 남아 있습니다. 사람이 손으로 옮기는 한 언젠가는 반드시 생기는 실수입니다.

이 실수는 실은 부주의 때문이 아닙니다. 값을 손으로 옮겨 적기 때문에 생깁니다. 손으로 옮기지 않고 앞 단계가 이미 알고 있는 값을 그대로 가져다 쓰면 어긋날 방법이 없습니다.

이번 시간에 배우는 이중 중괄호 {{ }}가 바로 그 "가져다 쓰기"입니다. 앞으로 이 강좌에서 하는 거의 모든 일이 이 문법 위에 얹힙니다 — 시트에 값을 채울 때도, 메일 본문에 이름을 넣을 때도, AI에게 민원 내용을 넘길 때도 전부 이것입니다.

1일차에서 가장 중요한 시간입니다 노드를 붙이는 것은 화면에 보이니까 금방 익숙해집니다. 하지만 값이 어디서 와서 어디로 가는지는 눈에 보이지 않습니다. 여기가 흔들리면 3강부터 계속 "왜 빈 칸으로 나오지?" 하며 헤매게 됩니다. 다른 시간보다 천천히 가도 괜찮습니다.

이번 시간에 만들 것

이전 노드에서 만든 값을 다음 노드가 표현식으로 그대로 이어받아 쓰는 워크플로우를 만듭니다. 값을 두 번 입력하지 않고도 앞 단계의 결과를 재사용하는 법을 익힙니다.

01강에서 만든 두 노드 뒤에 값 가져오기 노드 하나가 더 붙어, 모두 세 개가 한 줄로 이어진 모습이 됩니다.

따라하기

  1. 01강 워크플로우 이어서 열기 01강에서 만든 수동 실행 → 값 만들기 워크플로우를 그대로 엽니다. 화면을 이미 닫았거나 파일이 없다면 01강 하단에서 day1-01.json을 내려받아 불러오면 됩니다.
  2. 새 노드 추가하기 값 만들기 노드 오른쪽의 +를 눌러 Edit Fields (Set)를 고릅니다.
  3. 필드 추가하기 노드를 열었을 때 이름과 값을 입력할 빈 줄이 보이지 않는다면, Add Field를 눌러 줄을 하나 만듭니다. 이미 빈 줄이 하나 보인다면 그 줄을 그대로 씁니다. 빈 줄은 위부터 이름 칸(name), 자료형(String), 값 칸(value) 순서입니다. 아래 그림에 빨갛게 표시된 Expression은 5단계에서 누를 스위치입니다. 지금은 그냥 위치만 봐두세요.
  4. 필드 이름 정하기 name이라고 흐리게 적힌 맨 윗칸에 최종문구를 입력합니다. 노드 이름이 아니라 필드 이름입니다. 노드 이름은 마지막 단계에서 바꿉니다.
  5. 표현식 모드로 전환하기 값 칸을 한 번 클릭하면 그 줄 오른쪽 아래에 Fixed / Expression이라고 적힌 작은 전환 스위치가 나타납니다([그림 2-2]의 빨간 표시). 이걸 눌러 Expression 쪽으로 바꿔야 다음 단계에서 입력하는 내용이 그냥 글자가 아니라 계산식으로 처리됩니다. 이 스위치를 누르지 않고 다음 단계 내용을 그대로 입력해도 n8n은 오류를 내지 않습니다. 그냥 화면에 글자가 그대로 나올 뿐입니다. 이 강의에서 가장 놓치기 쉬운 지점이니 값 칸 오른쪽 아래를 잘 살펴보고 누르세요. 제대로 바뀌었다면 값 칸 왼쪽에 = 표시가 붙고, 칸 아래에 Result 미리보기 상자가 새로 생깁니다. 아직 아무것도 입력하지 않았으니 [empty]라고 나오고, 그 아래에 Tip: Execute previous nodes to use input data라는 안내가 함께 뜨는 것이 정상입니다. 그림 2-3은 스위치를 누른 직후라 맨 윗칸이 아직 name으로 비어 보입니다. 4단계에서 최종문구를 이미 넣었다면 그 자리에 글자가 보이는 것이 맞습니다.
  6. 표현식 입력하기 표현식 모드로 바뀐 값 칸에 {{ $json.인사말 }} 반갑습니다.를 입력합니다. 값 칸 오른쪽 끝의 확대 아이콘을 누르면 [그림 2-4]처럼 큰 편집창이 세 칸으로 열립니다. 왼쪽은 앞 노드들이 넘겨준 값 목록 (값 만들기 아래 인사말 · 안녕하세요, 홍길동님), 가운데 Expression은 표현식을 입력하는 곳, 오른쪽 Result는 그 표현식이 실제로 어떤 문장이 되는지 바로 보여주는 곳입니다. Result에 안녕하세요, 홍길동님 반갑습니다.가 나오면 제대로 된 것입니다. 앞에서 가져온 부분은 초록색으로 표시됩니다.
  7. 노드 이름 바꾸기 노드 제목을 더블클릭해 값 가져오기로 바꿉니다.
{{ $json.인사말 }}은 무슨 뜻인가요 $json은 바로 앞 노드가 넘겨준 데이터 전체를 가리킵니다. 값 가져오기 앞에는 값 만들기 노드가 있고, 그 노드는 인사말이라는 이름의 값을 만들었습니다. 그래서 $json.인사말은 값 만들기가 만든 인사말 값, 즉 안녕하세요, 홍길동님을 그대로 가리킵니다. 앞 노드에서 정한 이름을 한 글자도 다르지 않게 그대로 써야 값을 찾을 수 있습니다. [그림 2-4] 왼쪽 목록이 바로 $json의 내용물입니다 — 값 만들기 아래에 인사말 하나가 들어 있고, 그 옆에 실제 값이 적혀 있습니다. 이름이 헷갈리면 직접 입력하는 대신 이 목록에서 끌어다 놓아도 됩니다.

실행하고 확인하기

아래쪽 Execute workflow를 누릅니다. 노드마다 초록 체크가 뜨고, 값 가져오기를 누르면 오른쪽에 최종문구: 안녕하세요, 홍길동님 반갑습니다.가 보이면 성공입니다.

안 될 때

값 칸에 {{ $json.인사말 }} 반갑습니다.가 글자 그대로 보입니다 — 표현식 전환 스위치를 누르지 않았을 때 나타나는 증상입니다. 값 칸 왼쪽에 = 표시가 붙어 있는지 보면 바로 알 수 있습니다([그림 2-3]). 표시가 없으면 아직 Fixed 모드입니다.

필드 이름을 입력할 칸이 없습니다 — 아직 필드 줄이 만들어지지 않았습니다. Add Field를 눌러 빈 줄을 먼저 만드세요.

undefined 반갑습니다.가 나옵니다 — 앞 노드가 만든 필드 이름과 철자가 다릅니다. 값 만들기 노드의 필드 이름이 정확히 인사말인지 확인하세요.

Result에 값 대신 [empty]만 나옵니다 — 표현식은 맞는데 앞 노드를 아직 한 번도 실행하지 않아 미리 보여줄 데이터가 없는 경우입니다. 미리보기 아래에 Tip: Execute previous nodes to use input data라고 안내가 뜹니다. 워크플로우를 한 번 실행하면 그때부터 실제 값이 보입니다.

값 만들기 노드와 연결되어 있지 않습니다 — 두 노드 사이에 선이 이어져 있는지 확인하세요. 끊어져 있으면 값 만들기 노드 오른쪽 동그라미를 끌어다 값 가져오기 왼쪽에 놓으면 연결됩니다.
