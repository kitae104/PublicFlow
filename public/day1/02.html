02 데이터 흐름과 표현식

앞 노드의 값을 가져다 씁니다

왜 이게 필요한가

같은 서식의 안내 메일을 여러 사람에게 보내본 적이 있을 겁니다. 본문은 똑같고 이름과 연락처만 바뀌는 그런 메일 말입니다. 하나를 써놓고 복사해서 이름만 고쳐가며 보내다 보면, 김철수 님께 갈 메일에 박영희라는 이름이 남아 있습니다. 사람이 손으로 옮기는 한 언젠가는 반드시 생기는 실수입니다.

이 실수는 실은 부주의 때문이 아닙니다. 값을 손으로 옮겨 적기 때문에 생깁니다. 손으로 옮기지 않고 앞 단계가 이미 알고 있는 값을 그대로 가져다 쓰면 어긋날 방법이 없습니다.

이번 시간에 배우는 이중 중괄호 {{ }}가 바로 그 "가져다 쓰기"입니다. 앞으로 이 강좌에서 하는 거의 모든 일이 이 문법 위에 얹힙니다 — 시트에 값을 채울 때도, 메일 본문에 이름을 넣을 때도, AI에게 민원 내용을 넘길 때도 전부 이것입니다.

1일차에서 가장 중요한 시간입니다 노드를 붙이는 것은 화면에 보이니까 금방 익숙해집니다. 하지만 값이 어디서 와서 어디로 가는지는 눈에 보이지 않습니다. 여기가 흔들리면 3강부터 계속 "왜 빈 칸으로 나오지?" 하며 헤매게 됩니다. 다른 시간보다 천천히 가도 괜찮습니다.

이번 시간에 만들 것

이전 노드에서 만든 값을 다음 노드가 표현식으로 그대로 이어받아 쓰는 워크플로우를 만듭니다. 값을 두 번 입력하지 않고도 앞 단계의 결과를 재사용하는 법을 익힙니다.

01강에서 만든 두 노드 뒤에 값 가져오기 노드 하나가 더 붙어, 모두 세 개가 한 줄로 이어진 모습이 됩니다.

따라하기

  1. 01강 워크플로우 이어서 열기 수동 실행 → 값 만들기 워크플로우 그대로 열기 없으면 01강 하단에서 day1-01.json 내려받기
  2. 새 노드 추가하기 값 만들기 오른쪽 + → Edit Fields (Set)
  3. 필드 추가하기 빈 줄 없으면 Add Field 클릭
  4. 필드 이름 정하기 name 칸에 최종문구 입력
  5. 표현식 모드로 전환하기 값 칸 클릭 → Fixed / Expression 스위치 → Expression으로 가장 놓치기 쉬운 지점 — 값 칸 오른쪽 아래 스위치 꼭 확인 전환되면 왼쪽에 = 표시 + Result 미리보기 상자 생성
  6. 표현식 입력하기 값 칸에 {{ $json.인사말 }} 반갑습니다. 입력 확대 아이콘 → 왼쪽 값 목록 · 가운데 Expression · 오른쪽 Result 3단 편집창 Result에 안녕하세요, 홍길동님 반갑습니다. 확인
  7. 노드 이름 바꾸기 제목 더블클릭 → 값 가져오기로 변경
{{ $json.인사말 }}은 무슨 뜻인가 $json = 바로 앞 노드가 넘겨준 데이터 전체. $json.인사말 = 값 만들기가 만든 인사말 값을 그대로 가리킴. 필드 이름은 한 글자도 다르지 않게 써야 함.

실행하고 확인하기

  • Execute workflow 클릭
  • 값 가져오기 클릭 → 최종문구: 안녕하세요, 홍길동님 반갑습니다. 확인 = 성공

안 될 때

  • 값 칸에 {{ $json.인사말 }} 반갑습니다.가 글자 그대로 보임 — 표현식 전환 안 됨, 왼쪽 = 표시 확인
  • 필드 이름 입력 칸 없음 — Add Field로 빈 줄 생성
  • undefined 반갑습니다.가 나옴 — 값 만들기 필드 이름 철자(인사말) 확인
  • Result에 [empty]만 나옴 — 앞 노드 미실행 상태, 한 번 실행 후 재확인
  • 값 만들기 노드와 연결 안 됨 — 두 노드 사이 선 확인, 없으면 다시 연결

확인 문제

객관식Q1. 값 칸을 표현식(Expression) 모드로 바꾸면 칸 왼쪽에 어떤 표시가 붙나요?

  1. #
  2. =
  3. *
  4. %
정답 확인

정답: ② = 표시가 붙고, 칸 아래에 Result 미리보기 상자가 생깁니다.

객관식Q2. $json.인사말이 가리키는 것은?

  1. 지금 노드가 스스로 만든 값
  2. 바로 앞 노드가 넘겨준 데이터 중 인사말이라는 이름의 값
  3. 워크플로우 전체의 이름
  4. n8n 계정 정보
정답 확인

정답: ② $json은 바로 앞 노드가 넘겨준 데이터 전체를 가리키고, .인사말이 그중 그 이름의 값을 짚어냅니다.

단답형Q3. 이번 강의에서 만든 표현식 {{ $json.인사말 }} 반갑습니다.의 결과 값은 무엇인가요?

정답 확인
