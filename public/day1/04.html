이번 시간에 새로 만드는 노드

왜 이게 필요한가

새 민원이 들어올 때마다 담당자에게 일일이 알리는 대신, 접수와 동시에 메일이 자동 발송되면 보고 누락 없이 신속하게 처리 담당자에게 전달됩니다.

따라하기

어디에서 갈라져야 할까요 새 노드는 시트에 기록 뒤가 아니라 샘플 민원 노드에서 바로 갈라져야 합니다. 시트에 기록 노드를 지나면 그 노드의 출력은 "시트에 몇 번째 줄을 썼다"는 기록 결과로 바뀌어, 이름·연락처 같은 민원 내용 자체는 사라져 버립니다. 그래서 이번 강의도, 앞으로 나오는 새 노드도 전부 샘플 민원 하나에서 각각 직접 연결됩니다.
  1. Gmail 노드 추가하기 샘플 민원 노드 오른쪽 +를 누르고 Gmail을 고릅니다. 시트에 기록 노드가 아니라 반드시 샘플 민원 노드 오른쪽에서 눌러야 합니다.
  2. 자격증명 연결하기 03강에서 구글 시트 자격증명을 연결했던 것과 같은 방식입니다. 자격증명 칸에서 Create new credential을 고르고, 뜨는 화면에서 같은 개인 구글 계정으로 로그인한 뒤 권한 허용과 비슷한 문구의 버튼을 눌러 동의합니다. 이번에는 메일을 대신 보내도 되는지 묻기 때문에 03강에서 본 동의 화면과 문구가 다릅니다. 다른 화면이 나와도 잘못된 것이 아닙니다.

    창이 닫히고 n8n 화면으로 돌아와 자격증명 칸에 방금 만든 이름이 채워져 있으면 연결이 끝난 것입니다.

  3. 받는 사람 입력하기 To 칸 오른쪽의 표현식 전환 스위치를 눌러 Expression 모드로 바꾼 뒤 {{ $json.이메일 }}을 입력합니다. Resource와 Operation은 기본값인 Message·Send 그대로 두면 됩니다. 따로 바꿀 필요가 없습니다.
  4. 제목 입력하기 Subject 칸에 민원 접수를 입력합니다. 이 칸은 표현식으로 바꾸지 않고 그대로 글자로 입력합니다.
  5. 이메일 형식 바꾸기 Email Type 칸은 기본값이 HTML로 되어 있습니다. 이번 강의에서는 서식 없는 글로만 보낼 것이므로 Text로 바꿉니다.
  6. 본문 입력하기 Message 칸 오른쪽의 표현식 전환 스위치를 눌러 Expression 모드로 바꾼 뒤 아래 내용을 그대로 붙여넣습니다.

    담당팀께,
    아래와 같이 민원이 접수되었습니다.
    - 접수자명: {{ $json.이름 }}
    - 연락처: {{ $json.연락처 }}
    - 이메일: {{ $json.이메일 }}
    - 민원 종류: {{ $json.종류 }}
    - 상세 설명: {{ $json.상세설명 }}
    - 등록일: {{ $now.toFormat('yyyy년 MM월 dd일 HH시 mm분') }}
    내용 확인 후 신속한 처리 바랍니다.
    감사합니다.

    본문 전체가 표현식 모드라고 해서 전부 계산식이어야 하는 것은 아닙니다. "담당팀께," 같은 보통 글자와 {{ $json.이름 }} 같은 계산식이 한 칸 안에 섞여 있어도 됩니다. n8n은 이중 중괄호로 감싼 부분만 계산하고 나머지는 글자 그대로 둡니다.
  7. 노드 이름 바꾸기 노드 제목을 더블클릭해 접수 메일 보내기로 바꿉니다.

실행하고 확인하기

아래쪽 Execute workflow를 누른 뒤 본인 받은편지함을 확인합니다. 제목이 민원 접수인 메일이 도착해 있고, 본문의 접수자명·연락처·민원 종류가 채워져 있으며 등록일이 오늘 날짜로 나오면 성공입니다.

안 될 때

메일이 안 옵니다 — 먼저 스팸함을 확인하세요. 그다음 To 칸이 Expression 모드로 바뀌어 있는지 확인하세요. 모드를 바꾸지 않으면 n8n이 이메일 주소가 아니라 글자 {{ $json.이메일 }} 그대로를 받는 사람으로 해석해 발송에 실패합니다.

본문에 {{ $json.이름 }}이 글자 그대로 나옵니다 — Message 칸이 Expression 모드가 아닙니다. 전환 스위치를 다시 확인하세요.

시트에 기록 뒤에 붙였더니 값이 비어 옵니다 — 연결선이 시트에 기록에서 나와 있을 것입니다. 그 선을 지우고 샘플 민원 노드에서 새로 선을 이어 붙이세요.
