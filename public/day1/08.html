08 입력 폼으로 실제 접수받기

수동 실행을 폼으로 바꿉니다

왜 이게 필요한가

  • 지금까지는 민원 내용이 워크플로우 안에 박혀 있음 — 몇 번을 실행하든 항상 같은 사람의 같은 민원이 처리됨
  • 진짜로 쓰려면 민원인이 직접 입력할 창구가 있어야 하고, 그 창구는 n8n에 로그인하지 않은 사람도 열 수 있어야 함
  • 해결: 트리거를 입력 폼으로 교체 → 링크 하나만 있으면 누구나 제출 가능, 이 순간부터 연습이 아니라 서비스가 됨
이번 시간의 놀라운 점 트리거를 통째로 갈아끼우는데도 뒤에 붙은 노드는 하나도 고치지 않습니다 — 시트 매핑도, 메일 본문도, AI 프롬프트도, 조건 분기도 그대로 동작합니다. 필드 이름만 맞추면 됩니다.

이번 시간에 만들 것

지금까지 직접 실행 버튼으로 테스트하던 워크플로우를, 누구나 웹 폼으로 민원을 입력하면 자동으로 시작되도록 바꿉니다.

수동 실행·샘플 민원 삭제 → 민원 입력 폼 하나로. 폼에서 나가는 선은 세 개 — 시트에 기록, AI 안내문 작성, 생활인가?

따라하기

  1. 기존 트리거·데이터 노드 지우기 수동 실행·샘플 민원 선택 후 Delete 뒤 노드 왼쪽 입력점이 비게 됨 — 7단계에서 다시 연결
  2. Form Trigger 노드 추가하기 빈 캔버스 → Form 검색 → Triggers 아래 On new n8n Form event
    Actions 쪽 항목은 안 됨 — 번개 표시 붙은 Triggers 선택
  3. 폼 제목·설명 입력하기 Form Title = 민원 접수, Form Description = 민원이 있는 경우 이곳에서 신고하세요.
  4. 필드 다섯 개 추가하기 + Add Form Element로 5개 생성, 각각 Required Field 켜기

    이름 — Text Input
    연락처 — Text Input
    이메일 — Email 종류
    종류 — Dropdown
    상세설명 — Textarea

  5. 종류 필드에 드롭다운 옵션 넣기 Field Options에 세 칸: 생활, 음식물, 대형
  6. 노드 이름 바꾸기 민원 입력 폼으로 변경
  7. 끊어진 노드에 다시 연결하기 민원 입력 폼 출력점에서 시트에 기록·AI 안내문 작성·생활인가? 세 곳에 다시 연결
하류 노드는 하나도 손대지 않음 폼 필드 레이블이 샘플 민원과 같은 이름이라 {{ $json.이름 }} 표현식이 그대로 동작.

실행하고 확인하기

  • 활성화 스위치 켜기 → Form URLs의 Production URL 열어 제출
  • 시트 적재 + 접수 메일 + 3일 뒤 캘린더 일정 + 종류별 담당자 메일 = 성공
  • 테스트만 하려면 Execute workflow 후 Test URL 사용

안 될 때

  • 폼 화면 안 뜸 — 워크플로우 활성화 확인, 아니면 Test URL 사용
  • 제출해도 아무 일 없음 — 왼쪽 입력점에 선 없는 노드 확인
  • 일부만 동작 — 시트에 기록 뒤 선 확인
  • 값이 비어 들어감 — 폼 필드 레이블 철자가 샘플 민원과 같은지 확인
  • 활성화 안 됨 — 트리거가 Form Trigger인지 확인

확인 문제

객관식Q1. 폼 트리거로 바꾼 뒤에도 뒤에 붙은 노드들을 하나도 고치지 않아도 되는 이유는?

  1. n8n이 자동으로 값을 맞춰주기 때문에
  2. 폼 필드의 레이블을 샘플 민원과 같은 이름으로 맞췄기 때문에
  3. 표현식을 전혀 쓰지 않았기 때문에
  4. Form Trigger는 항상 값이 비어 있기 때문에
정답 확인

정답: ② 폼 필드 이름과 하류 노드의 표현식이 가리키는 이름이 같기 때문에, 데이터가 어디서 오든 이름만 맞으면 표현식이 그대로 동작합니다.

객관식Q2. 폼 트리거를 활성화(Active)하지 않고 테스트만 하고 싶을 때 쓰는 주소는?

  1. Production URL
  2. Test URL
  3. Webhook URL
  4. Admin URL
정답 확인

정답: ② Execute workflow 후 Test URL로 한 번만 쓸 수 있는 임시 폼 주소를 받을 수 있습니다.

단답형Q3. 폼에서 사라진 두 노드(수동 실행, 샘플 민원)의 역할을 이번 강의에서 대신하는 노드 하나의 이름은?

정답 확인

정답: 민원 입력 폼 — 워크플로우 시작과 민원 데이터 생성을 동시에 담당합니다.

이번 단계 워크플로우 받기

따라오다 막혔다면 이 파일을 받아 n8n에서 불러오면 이어서 진행할 수 있습니다.

불러온 뒤 반드시 확인하세요 이 파일에는 자격증명이 들어 있지 않습니다. 불러온 뒤 시트에 기록· 접수 메일 보내기·처리 마감 일정· Google Gemini Chat Model·생활 담당자· 일반 담당자 여섯 노드를 각각 열어 자격증명을 다시 골라야 합니다. 시트에 기록의 Document 칸과 처리 마감 일정의 Calendar 칸에는 각각 여기에_본인_시트_ID·본인이메일@example.com 자리표시자가, 생활 담당자·일반 담당자의 To 칸에도 본인이메일@example.com 자리표시자가 들어 있으므로 모두 본인 값으로 바꿔야 합니다(이번 강의부터 이메일 값은 폼 입력을 그대로 쓰므로 따로 바꿀 자리표시자가 없습니다). 시트 탭 이름은 시트1로 들어 있으니 본인 시트의 탭 이름이 다르면 목록에서 다시 골라야 합니다.
