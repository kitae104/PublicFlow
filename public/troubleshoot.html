막힐 때 보는 오류 10선

수업 중 가장 자주 나오는 막힘 열 가지 — 손을 들기 전에 먼저 보세요

먼저 이것부터

  1. 빨간 표시가 난 노드를 연다 오류는 대개 그 노드 하나에서 납니다. 위쪽의 빨간 메시지를 그대로 읽어 보세요.
  2. 왼쪽 INPUT에 값이 들어왔는지 본다 INPUT이 비어 있으면 앞 노드가 문제입니다. 한 칸 앞으로 가서 같은 방법으로 봅니다.
  3. 표현식 칸이면 이름을 한 글자씩 대조한다 {{ }} 안의 이름이 실제 노드 이름·열 이름과 철자·띄어쓰기까지 같은지 봅니다.

자주 막히는 열 가지

#이렇게 보인다대개 이것 때문이렇게 한다
1 노드에 빨간 표시, "자격증명이 없다" 서비스 연결(자격증명)을 아직 안 했거나, 내려받은 파일을 불러온 직후 노드를 열어 Credential에서 본인 계정을 고릅니다. 불러온 파일은 자격증명이 비어 있는 게 정상입니다
2 {{ $json.이름 }}이 빈 값 바로 앞 노드를 지나며 원래 값이 사라졌거나, 이름 철자가 다름 앞 노드 OUTPUT에서 실제 이름을 확인합니다. 몇 칸 앞 값이면 {{ $('노드 이름').first().json.이름 }}
3 "노드를 찾을 수 없다" / "unexecuted" $('...') 안의 노드 이름이 실제 제목과 다름, 또는 그 노드가 아직 실행 전 노드 제목을 더블클릭해 정확한 이름을 복사해 붙입니다. 앞 노드까지 Execute workflow로 한 번 실행
4 실행을 눌렀는데 아무 일도 없다 트리거가 없거나 연결이 끊김, 또는 마지막 노드에서 끝남 맨 앞에 트리거가 있는지, 노드마다 선이 이어졌는지 확인합니다
5 폼 주소를 열었는데 "등록되지 않음" 시험용 주소(Test URL)는 Execute workflow로 대기 중일 때만 열립니다 먼저 Execute workflow를 누른 뒤 그 폼 주소로 제출합니다. 상시로 쓰려면 Active를 켜고 Production URL을 씁니다
6 구글 연결에서 권한 오류 기관(@korea.kr 등) 계정이라 관리자가 외부 앱 연결을 막아 둠 개인 Gmail 계정으로 다시 연결합니다. 준비물 ① 구글 계정
7 Gemini 모델을 못 찾는다 / 할당량 초과 모델을 직접 고르지 않았거나, 무료 사용량을 넘김 Model 목록에서 models/gemini-2.5-flash를 직접 고릅니다. 초과라면 models/gemini-2.5-flash-lite로 바꾸거나 잠시 뒤 다시
8 시트 값이 엉뚱한 칸에 들어가거나 비어 있다 시트 머리글(1행)과 노드의 열 이름 철자가 다름 1행 머리글을 노드 매핑 이름과 한 글자씩 대조합니다. 탭 이름도 확인
9 메일이 안 온다 / 표와 서식이 글자 그대로 보인다 받는 주소 오류·스팸함, 또는 Email Type이 Text인 채 HTML을 보냄 받는 주소와 스팸함을 확인합니다. HTML을 보낼 때는 Email Type = HTML
10 고쳤는데 똑같이 나온다 저장하지 않았거나, 앞 노드의 이전 결과가 그대로 남아 있음 Ctrl+S로 저장한 뒤 Execute workflow로 처음부터 다시 실행합니다. Active가 켜진 워크플로우는 저장해야 반영됩니다

그래도 안 되면

  • 해당 강의 페이지의 "안 될 때" 항목을 봅니다 — 그 강에서만 나오는 막힘이 정리되어 있습니다
  • 각 강 맨 위의 "앞 강을 못 마쳤다면" 안내대로 앞 강 완성본 파일을 불러와 합류합니다
  • 화면 영어 메뉴가 헷갈리면 개념 지도와 화면 용어 사전을 봅니다
  • 옆자리 짝과 서로의 화면을 봐 주세요. 다른 사람이 보면 철자 오류는 금방 찾아집니다
