자동화는 이렇게 흘러갑니다

[트리거] ──→ [노드] ──→ [노드] ──→ [노드]
 언제 시작?     무엇을 할까?  (다음 일)   (다음 일)

예)  폼 제출  →  시트에 기록  →  메일 보내기  →  캘린더에 일정
  • 맨 앞에는 트리거가 하나 있고, 그 뒤로 노드가 줄줄이 이어집니다
  • 민원 한 건이 접수되면 그 한 건이 노드를 따라 흐르며 차례로 처리됩니다
  • 한 노드에서 선이 여러 갈래로 나뉘면 갈래마다 일이 따로 진행됩니다 (1일차 3강부터)

개념 여섯 개

용어업무에 빗대면한 줄 설명
트리거업무를 시작시키는 접수 도장워크플로우가 언제 시작할지 정합니다. 버튼, 폼 제출, 정해진 시각 등
노드한 가지 일만 맡은 담당자 한 명시트에 쓰기, 메일 보내기, AI에게 묻기처럼 무엇을 할지 정합니다
연결선서류가 다음 담당자에게 넘어가는 길노드와 노드를 잇습니다. 오른쪽 동그란 점에서 다음 노드로 끌어 놓습니다
항목서류 한 장 (민원 한 건)노드 사이로 흘러가는 데이터 한 건입니다. 시트의 한 줄과 비슷합니다
표현식서류 양식의 빈칸{{ }} 안에 적어 앞 노드의 값을 가져와 채웁니다
자격증명업무용 계정 로그인구글·텔레그램 같은 서비스에 한 번 연결해 두면 여러 노드가 재사용합니다

화면 용어 사전

n8n 화면의 메뉴는 영어로 나옵니다. 자주 만나는 것만 모았습니다.

화면에 보이는 말뜻
Execute workflow워크플로우 전체를 한 번 실행 (시험 실행)
Execute step / Test step지금 열어 둔 노드 하나만 실행
INPUT / OUTPUT노드로 들어온 값 / 노드가 내보낸 값. 막히면 가장 먼저 여기를 봅니다
+ (노드 오른쪽)다음 노드를 추가
Credential자격증명 (서비스 연결 정보)
Fixed / Expression값 칸의 두 가지 모드. 글자 그대로 쓰는 고정값, {{ }}로 계산하는 표현식
Active (활성화 스위치)켜 두면 트리거가 저절로 동작합니다. 시험 중에는 꺼 둡니다
Test URL / Production URL폼의 시험용 주소 / 상시 주소
Duplicate워크플로우 복제. 망칠까 걱정될 때 복사본에서 실험
Import from File내려받은 .json 워크플로우를 불러오기
Save저장 (Ctrl+S). 실행해도 저장은 따로 해야 하는 경우가 있습니다

자주 쓰는 표현식 여섯 개

식뜻나오는 곳
{{ $json.이름 }}바로 앞 노드가 넘겨준 이름 값1일차 2강
{{ $now.toFormat('yyyy-MM-dd') }}오늘 날짜를 2026-09-14 모양으로1일차 3강
{{ $now.plus(3,'days').toISO() }}3일 뒤 날짜·시각1일차 5강
{{ $('노드 이름').item.json.값 }}몇 칸 앞 다른 노드의 값을 이름으로 직접 가져옴2일차 P3
{{ $json.data.length }}목록에 든 건수2일차 P4
{{ 조건 ? A : B }}조건이 맞으면 A, 아니면 B2일차 P4
막혔을 때 순서 ① 막힌 노드를 열어 INPUT에 값이 들어왔는지 본다 → ② 표현식이 가리키는 이름이 철자까지 같은지 본다 → ③ 각 강의 "안 될 때"를 본다 → ④ 앞 강 완성본 .json을 불러와 합류한다.
