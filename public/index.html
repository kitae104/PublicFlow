1일차

민원 접수 자동화 시스템 만들기

여덟 강이 모두 하나의 워크플로우입니다. 매 시간 노드를 하나씩 얹어 앞 시간에 만든 것 위에 이어 붙입니다.

  1. 01 첫 워크플로우 노드를 놓고 실행해 봅니다 Manual Trigger
  2. 02 데이터 흐름과 표현식 앞 노드의 값을 뒤 노드에서 꺼내 씁니다 {{ }}
  3. 03 구글 시트에 자동 기록 접수와 동시에 시트에 한 줄이 쌓입니다 Google Sheets
  4. 04 이메일 자동 발송 접수 안내 메일이 저절로 나갑니다 Gmail
  5. 05 캘린더 일정 자동 생성 처리 마감일을 계산해 일정으로 잡습니다 Google Calendar
  6. 06 AI 안내문 자동 생성 민원 내용에 맞춘 안내문 초안을 받습니다 Gemini
  7. 07 조건에 따라 나누기 민원 종류에 따라 처리 경로를 가릅니다 If
  8. 08 입력 폼으로 실제 접수받기 주소만 알려주면 누구나 접수할 수 있습니다 Form Trigger

2일차

업무별 자동화 프로젝트

1일차에서 배운 것을 조합해 실제 업무에 바로 쓸 수 있는 자동화를 네 가지 만듭니다. 네 프로젝트는 서로 독립적이라 필요한 것부터 골라 만들어도 됩니다.

  • P1 공문서 요약과 기한 등록 PDF를 올리면 다섯 줄 요약은 텔레그램으로, 제출 기한은 캘린더로 자동 등록됩니다. Form · Extract from File · Gemini · Calendar · Telegram
  • P2 매일 아침 민원 브리핑 봇 매일 아침 9시, 쌓인 민원을 종류별로 정리해 메일로 보냅니다. Schedule · Google Sheets · Aggregate · Gmail
  • P3 AI 민원 분류와 결재 AI가 분류·답변 초안을 쓰고, 담당자가 승인해야만 민원인에게 발송됩니다. Form · Gemini · Google Sheets · Gmail 승인
  • P4 엑셀 오류 찾기 집행내역 엑셀을 올리면 한도 초과·증빙 누락 건만 골라 AI 점검 보고서를 메일로 보냅니다. Form · Extract from File · Filter · Gemini · Gmail
